# F1 Win Probability — Frontend

React + Vite + Tailwind CSS. See the [root README](../README.md) for full setup instructions.

```bash
npm install
cp .env.example .env
npm run dev
```

Runs at [http://localhost:5173](http://localhost:5173) and talks to the Node backend at `VITE_BACKEND_URL` (defaults to `http://localhost:3000`).
